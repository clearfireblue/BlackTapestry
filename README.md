# Black Tapestry

Single-page game. Upload everything in this folder to a GitHub repository, then:

1. Repo **Settings > Pages**.
2. Source: **Deploy from a branch**, branch `main`, folder `/ (root)`.
3. Open `https://<your-username>.github.io/<repo-name>/` on your iPhone in Safari.
4. Share button > **Add to Home Screen**. It will use the bridge icon and the name "Black Tapestry".

Saves live in each browser's local storage, so they stay on that device.
