# Dark Tapestry

Military branch of Black Tapestry on Alon 5077 rules: a star destroyer platoon of four squads, site-table missions, orbitals, downtime and Renown. Portraits live in `portraits/`.

Single-page game. Upload everything in this folder to a GitHub repository, then:

1. Repo **Settings > Pages**.
2. Source: **Deploy from a branch**, branch `DarkTapestry`, folder `/ (root)`.
3. Open `https://<your-username>.github.io/<repo-name>/` on your iPhone in Safari.
4. Share button > **Add to Home Screen**. It will use the bridge icon and the name "Dark Tapestry".

Saves live in each browser's local storage, so they stay on that device.
